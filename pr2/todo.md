Создать SPA-приложение на React с каталогом товаров, глобальной корзиной и сменой темы. Пользователь должен иметь возможность:

1.    Просматривать список товаров.
2.    Добавлять товары в корзину.
3.    Просматривать корзину и удалять товары.
4.    Менять тему приложения (light/dark).
5.    Перемещаться между страницами без перезагрузки (React Router).

Функционал
1.    Каталог товаров
o    Список товаров (минимум 5).
o    Каждый товар имеет: название, цену, кнопку “В корзину”.
o    Кнопка добавляет товар в глобальное состояние корзины.
2.    Корзина
o    Показывает список добавленных товаров.
o    Каждая строка: название, цена, кнопка удалить.
o    Итоговая сумма всех товаров.
o    Данные берутся из глобального состояния (Context или useReducer).
3.    Глобальная тема
o    Светлая/тёмная тема через Context.
o    Кнопка переключения темы в меню.
o    Цвет фона, текста и кнопок меняется по теме.
4.    Навигация
o    Меню со ссылками на все страницы.
o    Активная ссылка подсвечивается.
o    Использовать NavLink для React Router.
5.    Программные переходы (Redirect)
o    После добавления товара → можно перейти на /cart.
o    После успешного входа → редирект на /dashboard.
6.    Глобальное состояние
o    Использовать Context API или useReducer для:
    Корзины (cart)
    Тема (theme)
